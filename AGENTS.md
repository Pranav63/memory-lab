# Project instructions

- Keep this project separate from other projects and any employer work; use public AI research and user-provided notes.
- Credentials stay on the backend. Reference existing local environment files; never expose or commit secrets.
- Distinguish original paper briefs, uploaded documents, user findings, and model-generated claims.
- Memory is saved explicitly. Retain source provenance and previous versions when a finding is superseded.
- Use real Graphiti integration; never describe a fixture or keyword fallback as graph retrieval.
- Retrieval metrics measure evidence retrieval, not answer correctness. Keep expected evidence out of model prompts.
- Compare the same question, provider, corpus snapshot and context budget across conditions.
- Live inference happens only on explicit research, comparison or graph-index actions. Verify with small checks.
- Keep progressive disclosure, accessible keyboard controls and reduced-motion support.
- Verify persistence, source citations, frontend build and browser flows before completing changes.
